# 言うほどじゃないけど。

> 「言う」と「隠す」のあいだに、もう一つの伝え方を。

「言うほどじゃないけど。」は、自分から積極的に自慢するほどではないけれど、誰かにちょっと気づいてほしいことを、短い暗号としてそっと置いておく作品です。

相手は、興味をもったものだけを自分で解いて見ることができます。暗号を「秘密を守る壁」ではなく、「相手が知りたいと思ったときに近づく入口」として使い、「自分から言う／何も言わない」という二択をハックします。

**体験URL:** https://yuka-718.github.io/iu-hodo-janai-kedo/

## 体験できること

- サンプルカードの暗号を解き、隠れていた話を見つける
- 話の種類、本文、合言葉、暗号、公開範囲、写真、色を選んでカードをつくる
- ひとつずらし、さかさ文字、和文モールス、Unicodeの4種類から暗号を選ぶ
- 限定公開URLを渡すか、公開フィードへカードを流す
- 呼び名を出すか、匿名にするかを選ぶ
- 解かない／途中でやめる／返信しない自由を残す

## この作品が試したいこと

情報をそのまま公開するのでも、完全に隠すのでもなく、「解ける状態でそっと置いておく」。その一手間によって、送り手は押しつけずに差し出せるか、受け手は義務ではなく興味から近づけるかを試すコミュニケーション・プロトタイプです。

今後は「そのまま表示する」「タップすると開く」「短い暗号を解く」の3種類を比較し、暗号が単なる面倒ではなく、相手に興味をもつ時間や会話のきっかけになるかを検証します。

## ローカルで見る

ビルドは不要です。静的ファイルを配信してください。

```sh
python3 -m http.server 4173
```

その後、`http://localhost:4173` を開きます。

## 仕組みと注意

カードの内容はJSONとしてURLのフラグメントに格納されます。入力内容はサーバーへ送信しません。公開フィードはプロトタイプのため、作成した公開カードを端末内に保存し、あらかじめ用意した公開カードと一緒に表示します。

暗号はセキュリティ機能ではありません。共有リンクを知っている人は内容を読み取れるため、機密情報には使わない設計です。複数端末で共有される本番の公開フィードには、データベースと投稿管理機能が必要です。
